## 🔄 Цикл обновления данных (Polling)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ОБНОВЛЕНИЕ ДАННЫХ                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │

│      ↓                                                                     │
│  setInterval(300ms)                                                       │
│      ↓                                                                     │
│  this.updater.update()                                                    │
│      ↓                                                                     │
│  ┌──────────────────────────────────────────┐                             │
│  │  ModbusUpdater.update()                  │                             │
│  ├──────────────────────────────────────────┤                             │
│  │  1. api.readModbus()                    │                             │
│  │     ↓                                   │                             │
│  │     GET /api/modbus                     │                             │
│  │     ↓                                   │                             │
│  │     Получаем DataView со всеми данными  │                             │
│  │     (4096 регистров * 2 байта = 8KB)   │                             │
│  │     ↓                                   │                             │
│  │  2. Обновляем SPANS (числа)             │                             │
│  │     ↓                                   │                             │
│  │     Для каждого закэшированного спана:  │                             │
│  │     - берём regId, offset = regId * 2  │                             │

│  │     - обновляем element.textContent     │                             │
│  │     ↓                                   │                             │

│  │     - читаем 16-битное значение         │                             │

│  │     - переключаем классы on/off         │                             │
│  │     ↓                                   │                             │
│  │  4. Обновляем INPUTS (поля ввода)       │                             │
│  │     ↓                                   │                             │
│  │     Для каждого закэшированного input:  │                             │
│  │     - ПРОПУСКАЕМ если:                  │                             │
│  │       * регистр в процессе отправки     │                             │
│  │       * поле в фокусе (редактируется)   │                             │
│  │       * значение изменено пользователем │                             │
│  │     - иначе обновляем value              │                             │
│  └──────────────────────────────────────────┘                             │
│      ↓                                                                     │
│  Ждём 300 мс и повторяем                                                   │
│                                                                             │

## 🖥️ Серверная часть

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            СЕРВЕР (Express)                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  GET /api/modbus                                                          │
│      ↓                                                                     │
│  modbusService.getData()                                                  │
│      ↓                                                                     │
│  Возвращает Buffer из:                                                    │
│      ├── mmapDevice('/dev/modbus_rtu') → реальное устройство              │
│      └── testBuffer (fallback) → тестовые данные                          │
│                                                                             │
│                                                                             │
│  GET /api/loadConfig?file=projectConfig.json                             │
│      ↓                                                                     │
│  configService.loadConfigAsync()                                          │
│      ↓                                                                     │
│  Читает файл из /public/                                                 │
│      ↓                                                                     │
│  Кэширует в Map                                                          │
│      ↓                                                                     │
│  Возвращает JSON                                                          │
│                                                                             │
│                                                                             │
│  GET /blocksData.json                                                     │
│      ↓                                                                     │
│  express.static() → отдаёт файл из /public/                               │
│                                                                             │
│                                                                             │
│  POST /api/registers/:regId                                               │
│      ↓                                                                     │
│  Получает { state, registerType }                                        │
│      ↓                                                                     │
│  modbusService.writeRegister(regId, state, registerType)                 │
│      ↓                                                                     │
│  Записывает в буфер (mmap или testBuffer):                               │
│      ├── u2 → writeUInt16LE(value, offset)                               │
│      ├── s2 → writeInt16LE(value, offset)                                │
│      ├── f4 → writeFloatLE(value, offset)                                │
│      └── bN → битовая операция:                                          │
│              current | (1 << bitIndex)  // установить бит                │
│              current & ~(1 << bitIndex) // сбросить бит                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 🎯 Сводка по типам регистров

| Тип | Размер | Диапазон | Формат в конфиге |
|-----|--------|----------|------------------|
| `u2` | 2 байта | 0 ... 65535 | `"%d"`, `"%u"` |
| `s2` | 2 байта | -32768 ... 32767 | `"%d"`, `"%i"` |
| `f4` | 4 байта | ±3.4×10³⁸ | `"%f"`, `"%e"`, `"%g"` |
| `bN` | 1 бит | 0/1 | `"20:b0"` (регистр 20, бит 0) |

## 📌 Краткий итог

1. **Загрузка:** `app.js` → загружает `blocksData.json` → рендерит блоки
2. **Регистрация:** каждый блок регистрирует свои элементы в `modbusUpdater`
3. **Обновление:** каждые 300 мс → `api.readModbus()` → обновление всех элементов
4. **Запись:** `api.writeRegister()` → POST на сервер → запись в mmap
5. **Режим редактирования:** каждые 500 мс → перезагрузка `blocksData.json` → перерендер
