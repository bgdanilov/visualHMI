# CUBES_DATA — справочник полей blocksData.json

**Для кого:** наладчик, который собирает панели из готовых блоков («кубиков»).
**Что здесь:** поля каждого типа блока, их смысл, обязательность, примеры.
**Что НЕ здесь:** как добавить новый тип блока — см. `CUBES.md`.

---

## 📐 Общие правила

1. **Координаты** — в пикселях, от левого верхнего угла холста.
2. **Холст** — `1600 × 1200 px`. Блок с `x ≥ 1600` или `y ≥ 1200` **не виден**.
3. **`type`** — обязателен, определяет, какой кубик рендерить.
4. **`x`, `y`** — обязательны для всех блоков.
5. **`plain: true`** — убирает фон, рамку, тень. Полезно для блоков внутри `node-card`.
6. **`regAddress`** — номер регистра Modbus (0, 1, 2, …).
7. **`regType`** — тип регистра:
   - `u2` — unsigned 16-bit (0…65535)
   - `s2` — signed 16-bit (−32768…32767)
   - `f4` — float 32-bit (дробное)
   - `b0`…`b15` — бит `N` в 16-битном слове (0 или 1)
8. **Формат числа** — `format: [<строка>, <регистр>]`, где `<строка>` — printf-подобная (`%4.1f С`), `<регистр>` — число или `"N:type"`.
9. **Дочерние блоки** — только у `node-card`, в поле `children`.

## 🧱 Типы блоков

### 1. `only-title` — просто текст

| Поле | Обяз. | Тип | Пример | Описание |
|---|---|---|---|---|
| `type` | да | string | `"only-title"` | — |
| `x`, `y` | да | number | `20`, `20` | Позиция |
| `text` | да | string | `"РЕКУПЕРАТОР"` | Текст. `\n` → перенос строки |
| `plain` | нет | boolean | `true` | Без фона/рамки |

**Пример:**
{ "type": "only-title", "x": 20, "y": 20, "text": "Заслонка входная", "plain": true }

### 2. `only-number` — одно число

| Поле | Обяз. | Тип | Пример | Описание |
|---|---|---|---|---|
| `type` | да | string | `"only-number"` | — |
| `x`, `y` | да | number | `20`, `80` | Позиция |
| `format` | да* | array | `["%4.1f С", 0]` | Строка + регистр |
| `prefix` | нет | string | `"P = "` | Текст перед числом (если нет `format`) |
| `postfix` | нет | string | `" кВт"` | Текст после числа (если нет `format`) |
| `regAddress` | да* | number | `2` | Регистр (если нет `format`) |
| `regType` | нет | string | `"f4"` | Тип (если нет `format`) |
| `plain` | нет | boolean | `true` | Без фона/рамки |

\* Либо `format`, либо `regAddress` + `regType`.

**Пример (с format):**
{ "type": "only-number", "x": 20, "y": 80, "format": ["P = %4.1f кВт", 2], "plain": true }

**Пример (без format):**
{ "type": "only-number", "x": 20, "y": 80, "regAddress": 2, "regType": "f4", "prefix": "P = ", "postfix": " кВт" }

### 7. `send-button` — отправить группу регистров

| Поле | Обяз. | Тип | Пример | Описание |
|---|---|---|---|---|
| `type` | да | string | `"send-button"` | — |

  "x": 400, "y": 430,
  "regAddress": [16, 18, 20, 21],
  "text": "Сохранить"
}

### 9. `svg` — SVG с правилами

Загружает SVG из `src`, управляет по правилам в `rules`.

| Поле | Обяз. | Тип | Пример | Описание |
|---|---|---|---|---|
| `type` | да | string | `"svg"` | — |
| `x`, `y` | да | number | `60`, `20` | Позиция |
| `src` | да | string | `"/icons/fan.svg"` | Путь к SVG |
| `width` | нет | number | `50` | Ширина (по умолчанию 50) |
| `height` | нет | number | `50` | Высота (по умолчанию 50) |
| `rules` | нет | array | `[...]` | Правила (см. ниже) |
| `plain` | нет | boolean | `true` | Без фона/рамки |

**Правило:**
{
  "reg": "20:b2",
  "if": "== 1",
  "then": { "spin": "normal", "color": "#2ecc71" }
}

| Поле | Обяз. | Описание |
|---|---|---|
| `reg` | да | `"N:type"` — регистр и тип (например, `"20:b2"`) |
| `if` | нет | Условие (см. ниже). Если нет — правило срабатывает всегда |
| `then` | да | Эффекты: `spin`, `color`, `fill`, `opacity`, `visible`, `rotate`, `scale` |

**Условия (`if`):**

| Условие | Значение |
|---|---|
| `"== 1"` | равно 1 |
| `"!= 0"` | не равно 0 |
| `">= 5"`, `"<= 10"`, `"> 0"`, `"< 100"` | сравнения |
| `"range 20..80"` | 20 ≤ v ≤ 80 |
| `">= 20 && <= 80"` | 20 ≤ v ≤ 80 |
| `"== 1 || == 2"` | 1 или 2 |
| `"(>= 20 && <= 80) || == 0"` | 0, или 20…80 |
| `null` / `""` / нет поля | всегда `true` |

**Эффекты (`then`):**

| Эффект | Тип | Пример | Описание |
|---|---|---|---|
| `spin` | string \| number \| null | `"normal"`, `2`, `null` | Вращение: `normal` / `slow` / `fast` / `pause` / `reverse`; число — секунды на оборот; `null` — стоп |
| `color` | string | `"#2ecc71"` | Цвет SVG (`currentColor`) |
| `fill` | object | `{"target": "rect#level", "min": 0, "max": 100, "property": "height"}` | Заливка (для «бочек») |
| `opacity` | number | `0.5` | Прозрачность |
| `visible` | boolean | `false` | Скрыть/показать |
| `rotate` | number \| string | `90`, `"value * 3.6"` | Поворот в градусах |
| `scale` | number | `1.5` | Масштаб |

**Пример:**
{
  "type": "svg",
  "x": 60, "y": 20,
  "src": "/icons/fan.svg",
  "width": 50, "height": 50,
  "plain": true,
  "rules": [
    { "reg": "20:b2", "if": "== 1", "then": { "spin": "normal", "color": "#2ecc71" } },
    { "reg": "20:b2", "if": "== 0", "then": { "spin": null, "color": "#7f8c8d" } }
  ]
}

### 11. `node-card` — карточка-контейнер

Может быть toggle-карточкой (клик по пустому месту шлёт запись) или просто контейнером для детей.

| Поле | Обяз. | Тип | Пример | Описание |
|---|---|---|---|---|
| `type` | да | string | `"node-card"` | — |
| `x`, `y` | да | number | `125`, `535` | Позиция |
| `width` | нет | number | `160` | Ширина (по умолчанию 210) |
| `height` | нет | number | `345` | Высота (по умолчанию 345) |
| `name` | нет | string | `"Заслонка"` | Имя для confirm/popup |
| `click` | нет | object | `{"reg": "20:b0", "toggle": true, "confirm": true}` | Поведение по клику |
| `rules` | нет | array | `[...]` | Правила для визуального состояния (добавляют классы `on`/`off`) |
| `longPress` | нет | string | `"popup:trend"` | Действие по долгому нажатию |
| `popupData` | нет | object | `{"reg": 16, "title": "Заслонка"}` | Данные для popup |
| `children` | нет | array | `[...]` | Дочерние блоки |

**`click` — объект:**
- `reg` — `"N:type"` (например, `"20:b0"`).
- `toggle` — если `true`, читает текущее и пишет инвертированное (0→1, 1→0).
- `confirm` — если `true`, спрашивает «Вы уверены?».
- `value` — если `toggle: false`, пишет это фиксированное значение.

**`longPress` — варианты:**

| Значение | Иконка | Popup |
|---|---|---|
| `"popup:trend"` | 📈 стрелка-тренд | График тренда |
| `"popup:menu"` | ⋯ три точки | Контекстное меню |
| `"popup:settings"` | ⚙️ шестерёнка | Настройки (заглушка) |
| `"none"` / нет | — | Нет long-press |

**`children` — дочерние блоки:**

Любой блок из этого документа, кроме `node-card` (вложенность запрещена). Координаты `x`/`y` детей — **относительно карточки**, не холста.

**Пример:**
{
  "type": "node-card",
  "x": 395, "y": 180,
  "width": 160, "height": 345,
  "name": "Заслонка выходная",
  "click": {
    "reg": "256:b0",
    "toggle": true,
    "confirm": true
  },
  "rules": [
    { "reg": "256:b0", "if": "== 1", "then": { "class": "on"  } },
    { "reg": "256:b0", "if": "== 0", "then": { "class": "off" } }
  ],
  "longPress": "popup:trend",
  "popupData": { "reg": 17, "title": "Заслонка выходная" },
  "children": [
    { "type": "only-title", "x": 20, "y": 80, "text": "Заслонка выходная" },
    { "type": "image", "x": 55, "y": 20, "src": "/images/damper.jpg",
      "width": 50, "height": 50, "objectFit": "contain", "plain": true },
    { "type": "title-number", "x": 20, "y": 150, "plain": true,
      "text": "Температура", "format": ["%4.1f С", 0] }
  ]
}

**Поведение:**
- `click.toggle: true` — клик по пустому месту → confirm (если `confirm: true`) → запись инвертированного значения.
- `click.toggle: false` — клик по пустому месту пишет `click.value`.
- Нет `click` — клик по пустому месту ничего не делает.
- Клик по кнопкам/полям внутри — обрабатывается ими, карточка не реагирует.
- Долгое нажатие (800 мс) — открывает `longPress`-popup.
- Иконка в левом верхнем углу — подсказка (стрелка / три точки / шестерёнка).

### 12. `button` — простая кнопка со стейтами

Кнопка с фиксированными состояниями. Поддерживает два режима: `maintained` (переключение по клику) и `momentary` (нажал-отпустил).

| Поле | Обяз. | Тип | Пример | Описание |
|---|---|---|---|---|
| `type` | да | string | `"button"` | — |
| `x`, `y` | да | number | `20`, `330` | Позиция |
| `width` | нет | number | `100` | Ширина (по умолчанию 140) |
| `height` | нет | number | `70` | Высота (по умолчанию 50) |
| `name` | нет | string | `"Джог Вкл"` | Имя для confirm |
| `regAddress` | да | number | `256` | Номер регистра |
| `regType` | да | string | `"b6"` | Тип |
| `mode` | нет | string | `"momentary"` | `maintained` (по умолчанию) / `momentary` |
| `states` | да | array | `[...]` | Массив состояний |
| `confirm` | нет | boolean | `true` | Спрашивать подтверждение (только для `maintained`) |
| `inversion` | нет | boolean | `true` | Перевернуть on/off визуально |
| `plain` | нет | boolean | `true` | Без фона/рамки |

**Элемент `states`:**
{ "value": 1, "text": "Вкл", "color": "#c8e6c9", "class": "on" }

- `value` — что писать в регистр.
- `text` — текст на кнопке.
- `color` — цвет фона.
- `class` — CSS-класс (опционально).

**Пример (maintained):**
{
  "type": "button",
  "name": "Режим работы",
  "x": 125, "y": 915,
  "width": 140,
  "height": 80,
  "regAddress": 256,
  "regType": "b11",
  "mode": "maintained",
  "confirm": true,
  "states": [
    { "value": 1, "text": "Ручное",  "color": "#c7ab0b" },
    { "value": 0, "text": "Автомат", "color": "#c8e6c9" }
  ]
}

**Пример (momentary):**
{
  "type": "button",
  "name": "Джог Вкл",
  "x": 20, "y": 330,
  "width": 100, "height": 70,
  "regAddress": 256,
  "regType": "b6",
  "mode": "momentary",
  "states": [
    { "value": 1, "text": "Вкл", "color": "#c8e6c9" },
    { "value": 0, "text": "Вкл", "color": "#ffffff" }
  ]
}

**Поведение:**
- `maintained` — клик переключает на следующее состояние по кругу. Если `confirm: true` — спрашивает.
- `momentary` — `pointerdown` пишет `states[0].value`, `pointerup` — `states[1].value`. Без confirm.

## 🔤 Формат числа

Строка `format` использует printf-подобный синтаксис:

| Спецификатор | Пример | Значение |
|---|---|---|
| `%f` | `%f` | float, 2 знака |
| `%.1f` | `%.1f` | float, 1 знак |
| `%4.1f` | `%4.1f` | float, 1 знак, ширина 4 |
| `%d` / `%i` | `%4i` | целое, ширина 4 |
| `%u` | `%u` | unsigned |
| `%c` | `%c` | символ (для битовых) |
| `%e` / `%E` | `%e` | экспонента |
| `%g` / `%G` | `%g` | precision |

**Регистр в `format`:**
- `["%4.1f С", 0]` — регистр `0`, тип по спецификатору (`f` → `f4`).
- `["%4i %", "20:b0"]` — регистр `20`, тип `b0` (явно).

**Тип по умолчанию (если не указан):**
- `%f`, `%e`, `%g` → `f4`
- `%d`, `%i` → `s2`
- `%u` → `u2`
- `%c` → `b0`

## ⚠️ Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Блок не виден | `x` или `y` ≥ размеров холста | Проверь `x < 1600`, `y < 1200` |
| Блок «не на месте» | координаты детей `node-card` — **относительно карточки**, не холста | Пересчитай |
| Значение не обновляется | `regAddress`/`regType` не совпадают с регистром в ПЛК | Проверь `modbusUpdater` |
| `format` не работает | Неправильный спецификатор | См. «Формат числа» |
| Кнопка «Сохранить» неактивна | Нет «грязных» `title-input` с этими регистрами | Измени значение в `title-input` |
| `popup` не открывается | `longPress` = `"popup:xxx"`, но `xxx` не зарегистрирован | См. «longPress — варианты» |
| `node-card` не реагирует на клик | Нет `click` или `click.toggle: false` без `value` | Поставь `"click": { "reg": "20:b0", "toggle": true }` |
| `node-card` не реагирует на long-press | Драйвер не генерирует `pointerdown` | Проверь в DevTools Console |
